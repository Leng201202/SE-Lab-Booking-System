# Role statement — Chan Nyein Moe

**Student ID:** 6631503054  
**Role:** Designer

I owned the user-facing design story and helped turn the system requirements into journeys that each role can understand. My work covered the user journey, context and use-case diagrams, and the explanation of how Students, Technicians, Advisors, Deans, and operators interact with the system. I focused on making the important question visible to the user: which PC is genuinely available, what will happen after a request is submitted, and which action is available next.

I also contributed to the product’s usability and language experience. The interface supports English and Thai labels, and the design documentation explains the difference between one-day in-lab use, multi-day remote reservations, approval stages, requester cancellation, and account recovery. I helped ensure that the diagrams did not imply a permanent Student–Advisor assignment after the system moved to per-booking Advisor selection. This kept the visual model consistent with the current database and workflow.
